# NetLab

Windows 网络调试助手，支持 TCP / UDP / MQTT、自动应答和完整终端场景配置。

本仓库仅用于发布获准公开的编译后程序，源代码不公开。

## 下载

在 [Releases](https://github.com/Anzaynt/NetLab-Releases/releases) 下载已公开的版本。
选择 standalone 独立版，解压后运行 NetLab.exe，无需另外安装 .NET。
只有作者确认发布的版本才会出现在公开下载列表。

## 使用

UDP 左侧填写本地监听 IP/端口，发送区填写目标主机/端口。
顶部“保存场景/读取场景”可保存和恢复整套模拟终端配置。

JT808 当前支持 2013 非分包报文，不包含 2019 或媒体分包上传。
